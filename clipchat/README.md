# ClipChat

Self-hosted браузерный инструмент для синхронизации заметок и буфера обмена между устройствами в локальной сети. Визуально похож на мессенджер. Один пользователь, один пароль.

Работает на домашнем Linux-сервере, доступен с MacBook, телефона и других устройств в LAN.

## Возможности

- Синхронизация буфера обмена между устройствами в реальном времени (WebSocket)
- Текстовые заметки и загрузка файлов (до 10 МБ)
- Шифрование всех данных at rest (AES-256-GCM)
- Тёмный минималистичный интерфейс в стиле мессенджера
- PWA — устанавливается как приложение на телефон
- Закрепление важных сообщений
- Работа офлайн (кеширование через Service Worker)

## Быстрый старт

```bash
git clone <repo-url> && cd clipchat
npm install
npm start
```

Сервер запустится на `http://0.0.0.0:3000`. Откройте в браузере и установите мастер-пароль при первом запуске.

## Docker-деплой

```bash
docker-compose up -d
```

Данные сохраняются в `./data/` (SQLite база + загруженные файлы).

## Конфигурация

Переменные окружения (или файл `.env`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт HTTP-сервера |
| `DATA_DIR` | `./data` | Директория для БД и файлов |
| `SESSION_TTL_DAYS` | `30` | Время жизни сессии (дни) |
| `MAX_FILE_SIZE` | `10485760` | Макс. размер файла (байты) |

## Безопасность

### Что зашифровано
- Все тексты сообщений — AES-256-GCM
- Все загруженные файлы — AES-256-GCM
- Имена файлов в базе данных
- Ключ шифрования выводится из мастер-пароля через PBKDF2 (100 000 итераций, SHA-512)

### Что НЕ зашифровано
- Метаданные: timestamps, размер файлов, MIME-типы
- Трафик между браузером и сервером (HTTP, не HTTPS в LAN)

### Рекомендации
- Используйте сильный мастер-пароль
- Для доступа из интернета — настройте reverse proxy с HTTPS (nginx + Let's Encrypt)
- Ограничьте доступ к порту 3000 файрволом (только LAN)
- CORS ограничен адресами локальной сети (192.168.*, 10.*)

## Мобильная установка (PWA)

### iOS (Safari)
1. Откройте `http://<ip-сервера>:3000` в Safari
2. Нажмите кнопку «Поделиться» → «На экран Домой»

### Android (Chrome)
1. Откройте `http://<ip-сервера>:3000` в Chrome
2. Нажмите «Добавить на главный экран» в меню

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/auth/setup` | Установка пароля (первый запуск) |
| `POST` | `/api/auth/login` | Вход |
| `POST` | `/api/auth/logout` | Выход |
| `GET` | `/api/auth/check` | Проверка авторизации |
| `POST` | `/api/auth/change-password` | Смена пароля |
| `GET` | `/api/messages?limit=50&before=<id>` | Список сообщений |
| `POST` | `/api/messages` | Создать сообщение |
| `DELETE` | `/api/messages/:id` | Удалить сообщение |
| `PATCH` | `/api/messages/:id/pin` | Закрепить/открепить |
| `DELETE` | `/api/messages` | Удалить все |
| `POST` | `/api/files` | Загрузить файл |
| `GET` | `/api/files/:id` | Скачать файл |
| `ws` | `/ws?session=<token>` | WebSocket (real-time) |

## Стек

- **Backend:** Node.js, Express, WebSocket (ws), better-sqlite3, bcrypt
- **Frontend:** Vanilla JS + CSS (SPA, без фреймворков)
- **PWA:** Service Worker + Web App Manifest
