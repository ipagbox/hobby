# Hobby

A personal multi-project repository for small experimental tools and hobby subprojects.

## Subprojects

- [Board Box Planner](./board-box-planner/README.md) — A simple local-first 3D planner for designing box-like furniture from rectangular boards and generating a cut list.
- [Clipchat](./clipchat/README.md) — A self-hosted browser-based tool for syncing notes and clipboard across devices on a local network. Features a messenger-style UI, real-time WebSocket sync, end-to-end encryption (AES-256-GCM), file uploads, PWA support, and offline mode. Built with Node.js, Express, and vanilla JS.
